(low ≤ high), which indicate the range of indices of the elements that should to
be considered.
When called, the function would return the minimum value out of all of elements
in the low, low+1, …, high positions.


def min_in_lst(lst, low, high):
    if(low == high):
        return lst[low]
    else:
        mid_ind = (low + high) // 2
        min1 = min_in_lst(lst, low, mid_ind)
        min2 = min_in_lst(lst, mid_ind + 1, high)
        if(min1 < min2):
