# Coursework Instructions

- Help the user learn. Check answers with concise reasoning.
- Do not give full answers unless the user asks.
- Inspect files before you change them.
- Ask before edits, destructive commands, or external requests.
- Keep changes small. Test only approved changes.
- Use short, direct language.

## ECE2004 Assignment Style

- Use completed Homework 4 and Homework 5 notes as the main style references.
- Use `## 1`, `## 2`, and so on for numbered problems. Use plain lines such as `a.` for lettered parts.
- Write concise, auditable solutions. Show the governing equation, substitution, essential algebra, result, units, and requested direction or absorbed/delivered status.
- For circuit analysis, define nodes or mesh currents and the sign convention. Show each node or mesh equation before the result.
- Use `$...$` LaTeX, including equations on separate lines. Preserve units and significant figures. Do not box results unless the source style requires it.
- Use Obsidian embeds for diagrams. Put each embed after its circuit or current definitions.
- For long circuit problems, add a compact Markdown results table when useful.
- Do not add frontmatter or restate the full prompt. Keep prose minimal and separate steps with blank lines.
- Ask before choosing a folder because existing assignment placement is inconsistent.
