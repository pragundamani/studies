### Evens
How to qualify a number as even
$\forall k \in \mathbb{Z} \text{ there exists } n=2k \text{ which is even }$
$\text{ if } n=dk\text{,}\forall k\in \mathbb{Z}$   

### Odds
how to call a number as odd
$z \in \mathbb{Z}  \text{ is off iff } \exists k\in \mathbb{Z}  \text{ s.t. } n=2k+1$

### Prime:
$\text{ An integer } n>1 \text{ is prime iff } \forall r,s\in \mathbb{Z}^{+}$
$\text{ if } n = rs \text{ then either } r=1 \text{ and } s=n \text{ or } r=n \text{ and } s=n$
