### Arguments with multiple quantifiers
>[!example]- With multiple quanitifiers
>All math professors are funny
>joe is a math professor
>$\therefore \text{ joe is funny }$
>steps to form this argument:
>1. convert to if then statement
>	- $\forall \text{ people, P if P is a math professor then p is funny}$
>	- $\text{Joe is a math professor and also a person}$
>2. Universal instuntiation - if  a property is true for everythin in a set, it is true for an element in a set
>3. Universal Modus Ponens:
>	- $\forall x \in D \text{ if } P(x) \text{ then } Q(x)$
>	- $P(a) \text{ for a particular } a \in D$
>	- $\therefore Q(a)$
>	- And similarly for modus tollens
