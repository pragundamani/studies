### Conditional statemetns
$p \to q$ 
if p then q or p implies q
where p is the hypothesis (antecedent) and q is the conclusion (consequent)

>[!note] Theorem (*) 
> $p\to q \equiv \sim p \lor q$

| $p$ | $q$ | $p \to q$ |
| --- | --- | --------- |
| T   | T   | T         |
| T   | F   | F         |
| F   | T   | T         |
| F   | F   | T         |
vacuously true statements: $\text{if } 0=1 \text{ then } 1>10$, its true but feels whacky

### Different verions of conditionals
1. Converse: $q\to p$
2. Inverse: $\sim p \to \sim q$
3. Contrapositve (converse of the inverse): $\sim q \to \sim p$ 
	- Always logically equivalent to the statement itself

| $p$ | $q$ | $p \to q$ | $q\to p$ | $\sim p\to \sim q$ | $\sim q\to \sim p$ |
| --- | --- | --------- | -------- | ------------------ | ------------------ |
| T   | T   | T         | T        | T                  | T                  |
| T   | F   | F         | T        | T                  | F                  |
| F   | T   | T         | F        | F                  | T                  |
| F   | F   | T         | T        | T                  | T                  |

### Biconditionals
p only if q means if p then q
p if q means $q \to p$
if put together this becomes a biconditional statement
as in $p \leftrightarrow  q$ or $p \text{ iff } q$

| $p$ | $q$ | $(p\to q)\land (q \to p)$ |
| --- | --- | :-----------------------: |
| T   | T   | T                         |
| T   | F   | F                         |
| F   | T   | F                         |
| F   | F   | T                         |
##### more conditionals
1. p is a **sufficient condition** for q: $p \to  q$
2. p is a **necessary condition** for q: $\sim p \to \sim q$ or $q \to p$
3. p is a **necessary and sufficient condition** for q: $p \leftrightarrow  q$

### Unless statements
$p \text{ unless } q$ means if not q then p $\sim q \to  p$ 
but via Theorem ( * ) $p , q \equiv q \lor p$

### Valid and Invalid Arguments
- Argument = sequence of statements
	- statements except the final one are called premises or assumptions
	- the final one is called conclusion
	- We check arguments for validity by making a table
##### Valid Argument
for $p\to q$
p
$\therefore q$

| $p$ | $q$ | $p\to q$ | $q$ |                                                                |
| --- | --- | -------- | --- | -------------------------------------------------------------- |
| T   | T   | T        | T   | This is critical row where both $p$ and $p\to q$ are both true |
| T   | F   | F        | F   |                                                                |
| F   | T   | T        | T   |                                                                |
| F   | F   | T        | F   |                                                                |
##### Invalid Argument
for $p\to q$
q
$\therefore p$

| $p$ | $q$ | $p\to q$ | $p$ |                        |
| --- | --- | -------- | --- | ---------------------- |
| T   | T   | T        | T   | this is a critical row |
| T   | F   | F        | T   |                        |
| F   | T   | T        | F   | this is a critical row |
| F   | F   | T        | F   |                        |
since the critical rows can be true and untrue $\therefore$ argument is invalid
