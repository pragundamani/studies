###### 8. “There are no simple solutions to life’s problems”
[[3_2_textbook_exercises#Question 3.2.8|Question]]

#### Its informal negation is: **There is a simple solution to at least one of life’s problems.** Let $P(x)$ mean “$x$ is one of life’s problems” and $S(x,y)$ mean “$y$ is a simple solution to $x$.” The original statement is

$$\forall x\,\forall y\bigl((P(x)\land S(x,y))\to\bot\bigr),$$

or equivalently $\neg\exists x\exists y(P(x)\land S(x,y))$.

###### 9–10. Negations of the displayed conditional statements
[[3_2_textbook_exercises#Question 3.2.9|Question]]

#### Negation of $\forall x (P(x) \to Q(x))$ is $\exists x (P(x) \land \sim Q(x))$: some even integer is not divisible by 2, which is impossible, so the original is true; and some prime is even, namely 2, so “every prime is odd” is false.

###### 24(b). Primes and final digits
[[3_2_textbook_exercises#Question 3.2.24|Question]]

#### The statements are converses, and both are false. An integer greater than 2 that ends in 1, 3, 7, or 9 need not be prime (9, 15, 21, 27). A prime greater than 2 need not end in 1, 3, 7, or 9: 5 is prime and ends in 5.

###### 25(a)–(c). False converses
[[3_2_textbook_exercises#Question 3.2.25|Question]]

#### (a) Converse “if $x^2>4$ then $x>2$” is false: $x=-3$. (b) Converse “if $n$ is odd then $n^2$ is odd” is true for integers. (c) The circle converse is false: two disjoint circles do not share a center and do not meet in two points.

###### 26–31. Contrapositive, converse, and inverse
[[3_2_textbook_exercises#Question 3.2.26|Question]]

#### For “if $x>1$ then $x^2>1$”: contrapositive “if $x^2 \le 1$ then $x \le 1$” (true); converse “if $x^2>1$ then $x>1$” (false, $x=-2$); inverse “if $x \le 1$ then $x^2 \le 1$” (false, $x=-2$). (3.2.26)

#### For “if $x>2$ then $x^2>4$”: contrapositive “if $x^2 \le 4$ then $x \le 2$” (true); converse “if $x^2>4$ then $x>2$” (false, $x=-3$); inverse “if $x \le 2$ then $x^2 \le 4$” (false, $x=-3$). (3.2.27)

#### For “if $4$ divides $n$ then $n$ is even”: contrapositive “if $n$ is odd then $4$ does not divide $n$” (true); converse “if $n$ is even then $4$ divides $n$” (false, $n=2$); inverse “if $4$ does not divide $n$ then $n$ is odd” (false, $n=2$). (3.2.28)

#### For “if a figure is a square then it is a rectangle”: contrapositive “if a figure is not a rectangle then it is not a square” (true); converse “if a figure is a rectangle then it is a square” (false: a non-square rectangle); inverse “if a figure is not a square then it is not a rectangle” (false: same figure). (3.2.29)

#### For “if an integer is even then its square is even”: the contrapositive, converse, and inverse are all true. An even integer is $2k$, and its square is $4k^2$. (3.2.30)

#### For “if a real function is a polynomial then it is continuous”: contrapositive true; converse false, since $f(x)=\lvert x\rvert$ is continuous and not a polynomial; inverse false for the same function. (3.2.31)

###### 32. Derived statements for the divisibility conditional
[[3_2_textbook_exercises#Question 3.2.32|Question]]

#### Contrapositive: if $4 \nmid n$ or $2 \nmid n$, then $8 \nmid n$. Converse: if $4 \mid n$ and $2 \mid n$, then $8 \mid n$, false for $n=4$. Inverse: if $8 \nmid n$, then $4 \nmid n$ or $2 \nmid n$, false for $n=4$.

###### 33. Derived statements for “odd square implies odd integer”
[[3_2_textbook_exercises#Question 3.2.33|Question]]

#### Contrapositive: if a function is not continuous, then it is not differentiable. **True.** Converse: if a function is continuous, then it is differentiable. **False:** $f(x)=\lvert x\rvert$ at 0. Inverse: if a function is not differentiable, then it is not continuous. **False:** same example. (3.2.33)

###### 34. Differentiability and continuity
[[3_2_textbook_exercises#Question 3.2.34|Question]]

#### Answer 3.2.34

- Contrapositive: if a function is not continuous, then it is not differentiable. **True.**
- Converse: if a function is continuous, then it is differentiable. **False:** $f(x)=|x|$ at $0$.
- Inverse: if a function is not differentiable, then it is not continuous. **False:** $f(x)=|x|$ at $0$.

###### 38. Digit sequence 0204
[[3_2_textbook_exercises#Question 3.2.38|Question]]

#### **False.** In 0204 the digit 0 occurs both before and after 2, so not all 0s are left of all 2s. Formally $\forall$ positions $i,j$, if the digit at $i$ is 0 and the digit at $j$ is 2, then $i<j$. The negation is a 0 that is not left of some 2: positions of the last 0 and the 2.
