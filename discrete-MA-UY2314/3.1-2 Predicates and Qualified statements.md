Predicate sentence that contains a finit number of variables becomes a statement when an element from the domain is substititued in to the varaible
Domain is the set of all variables that can be used

use $P(x)$ to decide a predicate and after finding the value of x we can use such as $x=a$ $P(a)$ is either true or false
we built a set called the truth set: $$\{x \in D | P(x)\}$$
where:
$\{\}$ represents set of
$x \text{ in } D$ and D is domain
'$|$' represent such that
$P(x)$ becomes true

### Qualifiers
$\forall$ Universal qualifier
$\exists$ Existential qualifier
$\exists !$ Unique existential qualifier: there can be only one
$\nexists$ Not exists qualifier

$\mathbb{R}$ :: real numbers
$\mathbb{R}^{+}$ :: real positive numbers
$\mathbb{R}^{-}$ :: real negative numbers  
$\mathbb{R}^{\text{nonneg}}$ :: numbers $\geq$ 0
$\mathbb{R}^{\text{nonpos}}$ :: numbers $\leq$ 0

### How to negate qualifiers
$\sim (\forall x \in D, P(x))$ $\equiv$ $\exists x \in D \text{ s.t. }\sim P(x)$
$\sim (\exists x \in  D \text{ s.t. } P(x))$ $\equiv$ $\forall x\in D, \sim P(x)$


### ICC
Consider: $\forall x \in D, \text{ if } P(x) \text{ then } Q(x)$
Inverse: $\forall  x\in D, \text{ if } \sim P(x) \text{ then } \sim Q(x)$
Converse: $\forall x \in D, \text{ if } Q(x) \text{ then } P(x)$
Contrapositive: $\forall x\in D, \text{ if } \sim Q(x) \text{ then } \sim P(x)$
