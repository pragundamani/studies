# Checklist Snippets

Copy the lines you want into a note.

## Core

- [ ] task
- [x] done
- [/] work in progress
- [p] pending response
- [~] cancel
- [!] important

## Planning

- [a] appointment / meet
- [.] event
- [>] reschedule
- [s] schedule
- [f] future
- [t] travel

## Communication

- [m] contact
- [c] call
- [S] send
- [?] lookup
- [<] delegate

## Notes

- [-] note
- [i] idea
- [=] study
- [w] work
- [o] vis

## Actions

- [$] payment
- [u] upload
- [d] download
- [b] buy
- [R] rush
